# 奥德赛职业罗盘

一个面向迷茫期年轻人与应届生的 Codex Skill。它会用渐进式访谈，帮你厘清职业选择背后的目标、取舍和现实约束，再设计低成本的验证行动；不会替你宣称某条路是唯一正确答案。

## 使用

将本仓库的 `career-compass` 文件夹放入你的 Codex skills 目录，确保文件路径为 `skills/career-compass/SKILL.md`。然后可以这样开始：

> 我刚毕业，正在纠结两个方向。先不要给我建议，请一次问我一个问题，根据我的回答继续追问，帮我发现可能忽略的关键因素。

Skill 的完整说明见 [SKILL.md](SKILL.md)。分享或使用时，不必提供身份证号、家庭住址等与职业判断无关的敏感信息。
